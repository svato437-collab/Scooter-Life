# Scooter Life

2D трюковая игра на электросамокатах (HTML5 Canvas, без библиотек). Закатная тема, гараж и две трассы.

## Запуск
Положи `index.html`, `style.css`, `game.js` в одну папку и дважды кликни `index.html`.
В VS Code можно открыть папку и запустить через расширение Live Server (необязательно).

## Меню
- **Гараж:** четыре самоката стоят в ряд. Кликни по самокату (или листай `←` `→`), чтобы выбрать его; закрытые модели помечены замком.
- **Панель под гаражом:** характеристики, покупка, апгрейд мотора.
- **Трасса:** «Дикий склон» (холмы, кочки, трамплины, сложность растёт) или «Стант-площадка» (идеально ровный асфальт для вилли и стоппи). Рекорды считаются отдельно для каждой трассы.
- `Пробел` — быстрый старт из меню.

## Управление
- `→` / `D` — газ
- `←` / `A` — тормоз и задний ход
- `↑` / `W` — наклон назад (вилли)
- `↓` / `S` — наклон вперёд (стоппи)
- `R` — рестарт, `Esc` — гараж, `P` — пауза
- На телефоне появляются экранные кнопки.

## Как играть
- Держи вилли и стоппи — очки начисляются, когда вернёшь колёса на землю.
- На «Диком склоне» крути бэкфлипы и фронтфлипы на трамплинах.
- Голова коснулась земли или кривое приземление — авария и возврат на последний чекпоинт.
- Очки и монеты превращаются в 💰: покупай самокаты и качай мотор.
- Прогресс хранится в `localStorage` браузера.

## Настройка
- Самокаты: массив `SCOOTERS` в начале `game.js` (характеристики и внешний вид: `rim`, `shocks`, `twin`, `pods`, `glow`, `fender`). Рисует их `drawScooter()`.
- Трассы: массив `TRACKS` и функция `genChunk()`. Чтобы добавить новую, допиши запись в `TRACKS`, ветку в `genChunk()` и раскраску в `drawTerrain()`.
- Гараж: функция `drawGarage()` (стены, ворота с закатом, лампы, полки, пол).
- Закат в игре: `drawBackground()`.
- Физика: `GRAV`, `C` (высота центра масс), жёсткость и демпфирование подвески в `curStats()`.

Все четыре самоката (Spark, Rover, Bison, Titan) — оригинальные дизайны с вымышленными названиями.
